Letty 0.2.2 improves Linux input, settings persistence, application icons and
user-directory installation, with more reliable terminal file links.

- Preserves GTK input-method commits and preedit updates in order, including
  delayed and reentrant callbacks. Commits accompanying unconsumed keys are no
  longer lost, and modified keys reach the input method before shortcut fallback.
  Input queues remain bounded and window closure cancels pending delivery.
- Avoids a redundant redraw after synchronous input handling. Linux terminal
  font sizes now follow GTK font DPI consistently across text, grid and preedit.
- Allows settings to remain editable on filesystems that reject extended-attribute
  enumeration, while preserving separately available Linux ACLs and retaining
  conflict and metadata-error checks.
- Recognizes UTF-8, wide-character, quoted and escaped file paths, plus filenames
  containing spaces in multi-column terminal listings. This does not add PDF or
  spreadsheet preview support; ambiguous standalone paths should be quoted.
- Loads the bundled application icon for Linux windows, including direct launches
  from an extracted archive. Installation registers an application-menu entry
  matching the running window's application class.
- Installs versions under `~/.local/share/letty`, with the command linked at
  `~/.local/bin/letty`. Upgrades and rollbacks update the selected version behind
  the command and menu entry. A new uninstall script removes installed versions
  and matching launchers while retaining configuration and saved layouts.

### Linux download

Download **`letty-0.2.2-linux-x86_64.tar.gz`** and **`SHA256SUMS`**.

```sh
sha256sum --check SHA256SUMS
tar -xzf letty-0.2.2-linux-x86_64.tar.gz
cd letty-0.2.2-linux-x86_64
sha256sum --check SHA256SUMS
./bin/letty
```

For a versioned installation, run `./tools/install-user.sh`, then launch
`~/.local/bin/letty` or select Letty from the application menu. Add `~/.local/bin`
to `PATH` to run `letty` by name. Close Letty before uninstalling with
`~/.local/share/letty/current/tools/uninstall-user.sh`.

Existing `~/.local/opt/letty` installations are left in place. Pass that directory
explicitly to the install, rollback or uninstall script to manage the older location.

Requires x86_64 Linux 3.10+, glibc 2.17+, GTK 3.22.30+, GLib 2.56.1+, Cairo 1.15.12+,
an X11 display and a usable shell. Keep `bin/` and `share/` together. No Zig,
Python, sudo or system-library upgrade is needed to use the runtime package.

### Validation

Publication requires the tagged source's complete Linux CI release gate with
Zig 0.17.0, baseline CPU, ReleaseSafe and VT SIMD disabled. Checks include
unit/core/VT suites, hidden UI, GTK input ordering, settings metadata, X11 redraw
and window-icon properties, configuration, startup/restore, PTY lifecycle stress
and ELF ABI compatibility. `build-info.json` identifies the exact CI evidence.

The oldest supported kernel/library environment, actual NFS mounts, installed
input methods, remote X11/VDI and target latency/font comparisons remain separate
acceptance work. Deterministic input regressions do not establish the cause of
missing characters across a remote desktop connection.
