Letty's first Linux release provides a native Zig terminal built with nanoui and Ghostty VT.

- Windows, terminal/file workspaces, split panes and PTYs grow with available system resources.
- Local files and Markdown open in independent workspaces with language-specific icons.
- Includes tabs, splits, search, command palette, settings, themes, shell integration and layout restoration.
- Bundles Maple Mono Normal NL NF CN in four styles, with Chinese and Nerd Font glyphs; no font installation is needed.

### Linux download

Download **`letty-0.1.0-linux-x86_64.tar.gz`** and **`SHA256SUMS`** from the assets below.

```sh
grep ' letty-0.1.0-linux-x86_64.tar.gz$' SHA256SUMS | sha256sum --check
tar -xzf letty-0.1.0-linux-x86_64.tar.gz
cd letty-0.1.0-linux-x86_64
sha256sum --check SHA256SUMS
./bin/letty
```

For a versioned user-directory installation, run `./tools/install-user.sh`, then start `~/.local/opt/letty/current/bin/letty`.

The runtime requires x86_64 Linux, glibc 2.17+, GTK 3.22.30+, GLib 2.56.1+, Cairo 1.15.12+, an X11 display and a usable shell. No compiler, Python or separate terminal-font installation is needed. The default font is included under `share/letty/fonts/`; keep the extracted application resources together. Custom system font families remain configurable.

### Build and validation

GitHub Actions builds these assets with exactly Zig 0.17.0 for `x86_64-linux.3.10-gnu.2.17`, baseline CPU, ReleaseSafe and VT SIMD disabled. Publication requires that same Linux runner's unit/core/VT suites, complete hidden UI checks, GTK input/split smoke test, configuration checks, golden fixtures, 20 startup/restore launches, 256 lifecycle stress cycles and ELF ABI audit.

The archive contains dependency licenses, a source-bound release gate, `build-info.json` and per-file checksums. `letty-0.1.0-source.tar.gz` contains authored sources, locks and patches; bootstrap restores upstream dependencies.

Execution on the oldest supported kernel/library combination, remote X11/VDI, real IME and target performance remain separate acceptance work. This release's Linux runner tests do not certify every deployment environment.
