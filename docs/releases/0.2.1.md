Letty 0.2.1 improves native Markdown previews with structured blockquotes,
Mermaid flowcharts and common TeX formulas.

- Renders blockquotes with vertical rails, consistent indentation and wrapping.
  Nested quotes, quoted headings/lists, blank lines and explicit hard breaks retain
  their structure; copied text does not contain decorative rail characters.
- Renders an inert Mermaid flowchart subset with horizontal/vertical directions,
  rectangular/rounded/decision nodes, labeled arrows, feedback loops and dotted
  edges. Find reveals matching node labels; the Copy control preserves exact
  multiline Mermaid source. Large diagrams scroll and only visible strokes are drawn.
- Typesets inline and display math with fractions, square roots, sub/superscripts,
  Greek letters and common operators. Formula boxes remain intact when text wraps;
  headings scale them and tables reserve enough room for them. Copy and Find use TeX.
- Keeps unsupported Mermaid or TeX visible as source with an explicit notice.
  This is a bounded native subset, not a complete Mermaid or TeX engine. Subgraphs,
  other diagram types, custom styling, matrices, macros and scalable delimiters are
  not supported. See the [Markdown guide](https://github.com/BeriBeli/letty/blob/v0.2.1/docs/file-markdown-preview.md#markdown).
- Preserves local document editing, conflict checks, unsaved-change protection,
  the native Ghostty VT boundary and the existing Linux compatibility baseline.

### Linux download

Download **`letty-0.2.1-linux-x86_64.tar.gz`** and **`SHA256SUMS`**.

```sh
sha256sum --check SHA256SUMS
tar -xzf letty-0.2.1-linux-x86_64.tar.gz
cd letty-0.2.1-linux-x86_64
sha256sum --check SHA256SUMS
./bin/letty
```

For a versioned user installation, run `./tools/install-user.sh`, then launch
`~/.local/opt/letty/current/bin/letty`.

Requires x86_64 Linux 3.10+, glibc 2.17+, GTK 3.22.30+, GLib 2.56.1+, Cairo 1.15.12+,
an X11 display and a usable shell. Keep the bundled fonts, shell integration,
icons and other runtime resources together. Use GitHub's automatic source archives
for source code; bootstrap restores the pinned dependencies.

### Validation

The tagged source is built with Zig 0.17.0, baseline CPU, ReleaseSafe and VT SIMD
disabled. Publication requires fresh Linux unit/core/VT suites, complete hidden UI
checks, GTK smoke/input checks, configuration checks, VT goldens, 20 startup/restore
launches, 256 lifecycle stress cycles and an ELF ABI audit. `build-info.json` links
to the exact workflow's verification evidence.

The oldest supported kernel/library environment, remote X11/VDI, real IME and
target performance remain separate acceptance work.
