# Paper theme provenance

- Colors were extracted read-only from the embedded Paper theme in the [official Otty distribution](https://downloads.otty.sh/macos/Otty.dmg). Otty was not installed or run.
- Extraction date: 2026-10-19.
- Otty version/build: 1.6.2 / 1.6.2.
- Distribution SHA256: `c5019870d51b7dab149f121cf46f0a3d4b13add8c1c2ef157f0504aa94f8d0e4`.
- The [official theme documentation](https://docs.otty.sh/customization/themes) identified Paper as the default light theme. The theme site did not resolve during the original check, so the distribution resources were used to verify colors.
- Terminal foreground/background, the 16-color palette, panel background/surface/border, and token accent/muted match Paper values. Selection/cursor use default foreground/background semantics where Paper supplies no override.
- Only color data is reused; this project does not distribute Otty or its complete theme resources.
