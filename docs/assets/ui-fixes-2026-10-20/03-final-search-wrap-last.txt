## Build

On macOS, run `./script/build_and_run.sh` or use Run in Codex. Open `dist/Letty.app` directly; an Apple Silicon preview ZIP is also produced. Both platforms use nanoui. See the [macOS preview guide](docs/macos-preview.md).

Builds require Python 3, network access, and exactly Zig 0.17.0. `deps.lock.json` pins toolchain/source URLs and digests. Bootstrap writes to the project cache. Supported build hosts are macOS Apple Silicon and Ubuntu x86_64; no local amd64 container is used.

```bash
python3 tools/bootstrap.py
python3 tools/build.py
python3 tools/audit-elf.py zig-out/linux/bin
python3 tools/package.py
```

`tools/build.py --native` builds the native Zig GUI and runs unit, core, replay, and boundary checks. The active build has no C VT bridge or backend selector. The independently restored C baseline is retained in `dist/letty-vt-c-recovery-9b2f19589436.tar.gz`; see [recovery](docs/c-vt-recovery.md). Distribution requires current release-gate, hidden UI, startup, and stability evidence. Use `--skip-bootstrap --zig=/path/to/zig` to reuse the exact compiler. Linux remains `x86_64-linux.3.10-gnu.2.17` with `baseline` CPU.

Once hosted in GitHub, `.github/workflows/linux.yml` builds on an `ubuntu-24.04` x64 runner, checks artifacts, runs Xvfb smoke tests, and uploads tar.gz files. Uploading completed archives preserves executable permissions. Source archives restore locked dependencies through bootstrap and omit compilers/build caches.
